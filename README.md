# GRPS Title I Resource Center (retired)

This site has been retired. Its content, the GRPS Title I Toolkit, now lives in **Title I NOW**:

https://melatkins2-ops.github.io/grps-title-i-now/#tools

Every page in this repository now sends visitors straight to the Toolkit tab in Title I NOW, so old links and bookmarks still land in the right place.

## What happened to the content

- The Toolkit pages and the resource library are in Title I NOW (`title-i-resource-library.js`).
- The reference files (`resource_*.pdf`, `.pptx`, `.docx`) are in Title I NOW's `resources/` folder under the same names without the `resource_` prefix. The copies here are left in place so any direct file links that were shared still open.
- The Title I overview video is in Title I NOW as `GRPS_Title_I_Overview_Web.mp4` (a higher-resolution version of the same video).
- The full previous version of every page remains in this repository's Git history.
