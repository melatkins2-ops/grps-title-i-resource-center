Title I On-Site Review Evidence Structure

Create this folder structure at the beginning of the year. Evidence should demonstrate implementation and impact, not just the existence of documents.

Title I Evidence — 2026-27
00_Admin_Governance
01_Needs_Data_MICIP
02_Program_Design_Implementation
03_Fiscal_Allowability_Budget
04_Staffing_Qualifications_TimeEffort
05_Parent_Family_Engagement
06_Student_Services_ProgressMonitoring
07_Program_Evaluation
08_OnSite_Review_Response

Folder expectations

  • 00: approvals, program overview, key procedures, communications
  • 01: needs assessment, disaggregated data, stakeholder input, MICIP alignment
  • 02: program plan, evidence-based strategies, schedules, implementation monitoring
  • 03: budgets, coding, approvals, purchase evidence, fiscal monitoring
  • 04: job descriptions, qualifications, schedules, supervision, time/activity documentation
  • 05: annual meeting, policy/plan, compact, surveys, engagement evidence
  • 06: service logs, scholar selection/service evidence where applicable, progress monitoring
  • 07: annual evaluation, impact data, stakeholder review, continuation/modification decisions
  • 08: study guide, submitted evidence index, review team requests, compliance plans/corrective actions

File naming convention

YYYY-MM-DD_School_DocumentType_Description
Example: 2026-09-17_ExampleES_AnnualMeeting_Agenda.pdf
