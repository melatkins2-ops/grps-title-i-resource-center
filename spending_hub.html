What stronger spending documentation looks like

Need is visible

The rationale connects the cost to an approved Title I need, strategy, activity, or family-engagement objective.

Allowability is documented

The file shows why the cost is reasonable, necessary, allocable, and supplemental to the approved Title I work.

Approval happened before the purchase

Required approval and procurement steps occur before funds are obligated.

The evidence chain is complete

Rationale, approval, coding, invoice/receipt, and proof of actual use all tell the same story.

Example

Too weak

Invoice + receipt only.

Stronger

Need/rationale + approval + procurement as applicable + coding + invoice/receipt + evidence the item/service was used for the approved Title I purpose.

Before you spend

1. Identify the need

What approved Title I need, strategy, activity, or family-engagement objective does this cost support?

2. Check current allowability

Use the current MDE Allowable Use FAQ and current federal requirements—not an older local list when the guidance conflicts.

3. Check coding

Confirm the current function and object code and whether the cost requires prior approval.

4. Keep evidence

Retain rationale, approval, ordering/payment record, coding, and evidence the item/service was used for the approved purpose.

Do not treat a resource list as approval. Every cost still has to be reasonable, necessary, allocable, aligned to the approved program, and properly documented.

Code by purpose—not by where money is available

Use the function code that describes why the expenditure exists. Function, object, and fund/grant answer different questions.

Function

Why / purpose.

Object

What is purchased or paid.

Fund / grant

Which funding source pays the cost.
