GRPS TITLE I

About this Resource Center

End-user pilot release • September 2026

What this is

A working Title I support system designed to help GRPS staff complete common Title I responsibilities, make stronger decisions, document implementation, and find current requirements and examples.

Source hierarchy

Current federal requirements and current MDE guidance control. Current-year GRPS procedures are the operating source for district processes. MASFPS materials and district examples are supplemental implementation resources and do not replace current requirements.

When guidance changes

State & Federal Programs should review affected tools, dates, links, and examples before the Resource Center is treated as updated. A dated resource should not be assumed current merely because it remains in the library.

Local saving

Some working tools save progress in the browser being used. Saved work is not a district system of record and may not follow the user to another device or browser. Required documentation should still be retained in the appropriate GRPS recordkeeping location.

Pilot status

This version is ready for structured end-user testing. Feedback should focus on accuracy, task completion, clarity, missing supports, accessibility, and usability.
